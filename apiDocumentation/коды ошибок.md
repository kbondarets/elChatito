Коды ошибок
Все ошибки приходят в одном формате — таком же, как у OpenAI, поэтому SDK
разбирают их сами:
## {
## "error": {
"message": "The model `openai/gpt-9` does not exist or is disabled.",
## "type": "invalid_request_error",
## "code": "model_not_found",
## "param": "model"
## }
## }
Опирайтесь на code: он машиночитаемый и не меняется. Текст message написан для
человека и со временем может стать другим. Поле param указывает на конкретное
поле запроса, если ошибка в нём.
