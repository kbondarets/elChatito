# elChatito

Локальный чат для моделей apimira ([OI]-совместимый API). Работает на вашем компьютере,
ключ хранится только у вас и в браузер не попадает.

## Что уже умеет (версия 1)

- Создавать несколько чатов и переключаться между ними.
- **Сразу открывать чат при запуске**: приложение само открывает последний чат,
  а если чатов ещё нет — создаёт новый. Нажимать «+ Новый чат» нужно только тогда,
  когда хочется начать новую переписку.
- Переименовывать чаты (кнопка ✎) и удалять их (кнопка ×, с подтверждением).
- Выбирать модель из выпадающего списка (все модели каталога с пометкой типа).
- Отправлять сообщение и получать ответ модели.
- **Прикреплять файлы и фото** (кнопка 📎): картинки модель «видит», из документов
  извлекается текст — см. раздел «Файлы и фото».
- Смотреть ответ «вживую»: текст печатается по мере генерации, с мигающим курсором.
- Продолжать диалог в том же чате (модель помнит контекст чата).
- Сохранять чаты на диск — они не пропадают при перезапуске.

## Быстрый запуск

1. Впишите свой ключ в файл `.env` (строка `apimira_api_key=...`).
2. Дважды щёлкните `start.bat`.

Через несколько секунд откроется браузер на `http://127.0.0.1:5173`.
Чтобы остановить — закройте чёрное окно терминала.

## Запуск вручную

```powershell
npm install     # только при первом запуске
npm run dev     # бэкенд на 3000 + интерфейс на 5173
```

Затем откройте `http://127.0.0.1:5173`.

```
│  ├─ uploads.js          хранение загруженных файлов
│  ├─ extract.js          извлечение текста из PDF/DOCX
│  └─ store.js            хранение чатов в data/chats.json
├─ client/                интерфейс: React + Vite
│  ├─ index.html
│  └─ src/App.jsx         вся логика экрана чата

```

## Список моделей

Список не фиксирован — сервер сам тянет его из apimira при запуске:

- `GET /v1/models` — какие модели доступны;
- `GET /v1/account/pricing` — название, тип и возможности каждой модели.

В выпадающем списке — все модели каталога с пометкой типа: «GPT-6 Astra · чат»,
«Veo 3.1 · видео», «GPT Image 2 · картинки». Модели с возможностью видеть картинки
помечены глазом 👁. Модели типов «картинки» и «видео» в текстовом чате не работают
(шлюз вернёт ошибку) — они показаны для полноты картины.

Чтобы обновить список — просто перезапустите приложение.

Посмотреть список вручную:

```powershell
node scripts/list-models.js
```

## Файлы и фото

Кнопка 📎 в поле ввода прикрепляет файлы к сообщению. Как они попадают в модель:

| Файл | Что делает elChatito |
| --- | --- |
| Картинки (PNG, JPEG, WebP, GIF, BMP, AVIF) | Отправляются как изображения — модель их «видит». Нужна модель с 👁. |
| Текст и код (TXT, MD, CSV, JSON, XML, YAML, JS, PY, …) | Содержимое уходит в модель как текст. |
| PDF | Из содержимого извлекается текст (best-effort). |
| DOCX | Из содержимого извлекается текст. |
| Прочее | Отклоняется с понятным сообщением. |

Ограничения: до 20 МБ на файл; для PDF понимается только текст из простых шрифтов
(сложные и сканированные документы могут дать пусто). Файлы хранятся локально в
`data/uploads/` и в браузер не уходят; на сервер отправляются только выбранные вами файлы.

## Полезные команды

```powershell
npm run dev      # разработка: сервер + интерфейс
npm run build    # собрать интерфейс в папку dist

```

## Работа с git

Проект хранится на GitHub, ветки ведутся по простой схеме:

- **`main`** — всегда рабочая версия (то, что запускается). Напрямую в неё ничего не льём.
- **`feature/<имя>`** — новая возможность (например, `feature/system-prompt`).
- **`fix/<имя>`** — исправление ошибки.

Каждая доработка делается в отдельной ветке, созданной от `main`, с прогоном тестов;
в `main` ветка вливается только после проверки. Так новая фича не может сломать
стабильную версию.
